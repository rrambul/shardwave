# Experiments

One file per experiment, from Sprint 004 on: `NNN-short-title.md`.

Required sections:

- **Setup** — machines, commit hash, model, stage split, network path.
- **Hypothesis** — what we expect and why, written *before* running.
- **Results** — the numbers. Tables. Raw data under `NNN-short-title/raw/`
  (gitignored if large).
- **What we learned** — including what surprised us and what it changes.

If it has no numbers, it is not an experiment; it is a note, and it belongs in
the north star's open questions or in an ADR's context.
